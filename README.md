# AI-Powered-Math-Tutor

## Project Overview

This project aims to develop an AI-powered math tutor to assist young school students in solving basic math word problems. The system uses a fine-tuned generative AI model to provide step-by-step solutions, enhancing students' problem-solving skills and math education experience.

## Key Objectives

- Implement an interactive AI model for solving math word problems
- Provide personalized, step-by-step solutions to various math problems
- Improve student engagement and understanding of mathematical concepts
- Offer scalable educational support across different curricula and cultures

## Data Analysis

The team processed and analyzed a dataset of math word problems, focusing on:

- Extracting a subset of problems and solutions from a larger dataset
- Preparing data for model fine-tuning
- Ensuring data quality and diversity to reduce bias

## Key Features

- Step-by-step problem-solving guidance
- Support for a wide range of math topics and difficulty levels
- Personalized learning experience

## Model Training

- Fine-tuned a GPT-3.5 model on a dataset of math word problems
- Used first 100 rows for training, next 100 for validation, and another 100 for testing
- Transformed datasets into AI-understandable format and saved as .jsonl files
- Created and tracked fine-tuning jobs to optimize model performance

## Technologies Used

- Python
- Jupyter Notebook
- OpenAI API
- Data processing libraries (e.g., Pandas)

## Conclusion

The AI-Powered Math Tutor project demonstrates significant potential to transform math education and address global learning challenges by providing interactive, step-by-step solutions to word problems. Through its commitment to fairness, transparency, and continuous improvement, this initiative takes a significant step towards improving global learning outcomes and making quality math education more accessible to students worldwide.
